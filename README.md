# Ejercicios de Control de Procesos

Actividades interactivas de Control de Procesos (Universidad Distrital Francisco José de Caldas), hechas por **Jheison Estiben Bernal Cucaita**.

Sitio: https://jheisonbernal9922-code.github.io/

- **Reductor de bloques** — reducción de diagramas de bloques con las reglas del álgebra de bloques, modo cálculo y práctica de fracciones.
- **Taller de analogías** — analogía fuerza-voltaje: simplificar, contar mallas, traducir elementos y escribir las ecuaciones.
